# Upload the FinSmart binary archive

The source archive supplied for this project is a compiled Android package ZIP, approximately 29 MB. It was not committed because the connected GitHub file interface supports UTF-8 text files and cannot upload arbitrary binary bytes.

To add it, upload `FinSmart-compiled-android-package.zip` into this folder using Git or GitHub's web interface. The archive is a compiled app artifact, not the editable Android Studio source project.

For further development, add the original Android Studio project separately. Do not commit service-account keys, signing keys, passwords, or other secrets.
