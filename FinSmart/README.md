# FinSmart — compiled Android package

This folder contains the compiled Android application package uploaded for project review.

## Important

- This is a compiled Android package archive, not the original Android Studio source project.
- It contains Android resources, compiled DEX bytecode, and packaged libraries.
- It is not directly editable as a normal Kotlin/Gradle project.
- The archive should be treated as a build/release artifact, not as source code.

For source-level development, add the original Android Studio project separately (including `app/src`, Gradle build files, and safe Firebase configuration/rules). Do not commit service-account keys, signing keys, or other secrets.
